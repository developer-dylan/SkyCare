# SkyCare ☁️

Una aplicación web moderna para consultar información meteorológica y gestionar datos climáticos de diferentes ciudades.

## 📋 Descripción

SkyCare es una plataforma web que permite a los usuarios consultar información meteorológica en tiempo real, gestionar un dashboard personalizado y realizar búsquedas de clima por ciudad. La aplicación está diseñada con una interfaz intuitiva y responsive.

## ✨ Funcionalidades Principales

### 🌤️ Consulta Meteorológica
- Búsqueda de clima por ciudad
- Información meteorológica en tiempo real
- Datos detallados de temperatura, humedad y condiciones climáticas

### 📊 Dashboard de Usuario
- Panel personalizado para cada usuario
- Gestión de ciudades favoritas
- Visualización de datos meteorológicos históricos

### 🎨 Interfaz de Usuario
- Diseño responsive y moderno
- Página de inicio (landing page) estilizada
- Experiencia de usuario optimizada

### 🗄️ Gestión de Datos
- Base de datos para almacenar información de usuarios
- Sistema de gestión de ciudades y preferencias
- Almacenamiento de datos meteorológicos

## 🛠️ Tecnologías Utilizadas

- **Frontend**: HTML5, CSS3, JavaScript (75.2%)
- **Estilos**: CSS personalizado (23.8%)
- **Estructura**: HTML semántico (1.0%)
- **Base de Datos**: Sistema de almacenamiento local

## 🌐 Integraciones con APIs

### API Meteorológica
La aplicación integra servicios de datos meteorológicos para obtener:
- Condiciones climáticas actuales
- Pronósticos extendidos
- Datos de temperatura y humedad
- Información de precipitaciones

*Nota: La API específica utilizada puede variar según la configuración del proyecto*

## 🚀 Instalación y Configuración

### Prerrequisitos
- Navegador web moderno
- Servidor web local (opcional)

### Pasos de Instalación

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/contrerinhaz/SkyCare.git
   cd SkyCare
   ```

2. **Instalar dependencias** (si aplica)
   ```bash
   npm install
   ```

3. **Ejecutar la aplicación**
   - Abrir `index.html` directamente en el navegador, o
   - Usar un servidor local:
   ```bash
   npm start
   ```

## 💻 Uso

1. **Acceso a la aplicación**: Abrir la página principal en el navegador
2. **Búsqueda de clima**: Utilizar la función de búsqueda para consultar el clima de cualquier ciudad
3. **Dashboard**: Acceder al panel personalizado para gestionar ciudades favoritas
4. **Visualización**: Consultar datos meteorológicos detallados y actualizados

## 🔧 Configuración de API

Para utilizar las funcionalidades meteorológicas completas:

1. Obtener una clave de API del servicio meteorológico elegido
2. Configurar la clave en el archivo de configuración correspondiente
3. Verificar la conectividad con la API
